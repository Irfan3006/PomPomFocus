# PomPomFocus - Cute Pomodoro Timer 🐰

A delightful and cute Pomodoro timer web application to boost your productivity with a playful design and comprehensive features.

## Features 🌟

### ⏰ Timer Functionality
- **Standard Pomodoro**: 25 minutes work, 5 minutes break
- **Custom Durations**: Work times (25, 50, 75, 100 minutes), Break times (5, 10, 15, 20 minutes)
- **Full Controls**: Start, Pause, Reset functionality
- **Visual Progress**: Circular progress indicator with smooth animations
- **Auto-switching**: Automatically switches between work and break sessions

### 🎨 Cute Design
- **Cartoon Aesthetic**: Playful colors and cute illustrations
- **Responsive Layout**: Works perfectly on mobile, tablet, and desktop
- **Pink Mode**: Toggle between light and pink themes
- **Smooth Animations**: AOS (Animate On Scroll) and CSS transitions
- **Custom Font**: Fredoka font for a friendly, playful look

### 🔊 Audio Features
- **Cute Notification Sounds**: Web Audio API generated sounds
- **Volume Control**: Adjustable volume slider
- **Sound Effects**: Start sound and completion melody

### 📊 Session Tracking
- **Local Storage**: All data saved locally
- **Statistics Dashboard**:
  - Total sessions completed
  - Total focus time
  - Sessions completed today
  - Current day streak
- **Data Management**: Clear all data option

### ✨ Additional Features
- **Current Time Display**: Shows date and time
- **Motivational Messages**: Random encouraging messages during sessions
- **Mode Indicators**: Visual indicators for Work/Break modes
- **Browser Notifications**: Native notifications when sessions complete
- **Persistent Settings**: Theme and volume preferences saved

## Technology Stack 💻

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with animations and transitions
- **Vanilla JavaScript**: No external libraries required
- **Bootstrap 5**: Responsive grid and components
- **AOS**: Scroll animations
- **Web Audio API**: Custom sound generation
- **Local Storage**: Data persistence

## Getting Started 🚀

### Local Deployment
1. Clone or download the project files
2. Open `index.html` in your web browser
3. Start using PomPomFocus immediately!

### No Build Process Required
This is a static web application - just open the HTML file and start using it!

## Usage Guide 📖

1. **Start Timer**: Click the "Start" button to begin a work session
2. **Customize Duration**: Use the dropdowns to set custom work/break times
3. **Adjust Volume**: Use the volume slider for sound preferences
4. **Toggle Theme**: Click "Pink Mode" for a different color scheme
5. **View Stats**: Check your productivity statistics in the dashboard
6. **Clear Data**: Reset all statistics if needed

## Features in Detail 🔍

### Timer Modes
- **Work Mode**: Focus time with blue/pink progress ring
- **Break Mode**: Relaxation time with green progress ring
- **Auto-progression**: Automatically switches between modes

### Visual Feedback
- **Progress Ring**: Circular SVG animation showing time remaining
- **Pulse Animation**: Activates when less than 10 seconds remain
- **Mode Badges**: Clear visual indicators for current mode
- **Hover Effects**: Interactive buttons with ripple animations

### Audio System
- **Start Sound**: Gentle beep when timer starts
- **Completion Sound**: Cute melody when session ends
- **Volume Control**: Real-time volume adjustment
- **Web Audio API**: No external audio files needed

### Data Persistence
- **Session History**: Tracks all completed sessions
- **Streak Calculation**: Maintains consecutive day streaks
- **Daily Reset**: Automatically resets daily counters
- **Settings Storage**: Remembers theme and volume preferences
